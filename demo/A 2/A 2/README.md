# SmartStock

SmartStock is an AI-powered inventory decision-support demo for retail replenishment.

## One-Click Start

Double-click:

```text
START_SMARTSTOCK_DEMO.bat
```

It starts a local static server for `frontend/` and opens the demo at:

```text
http://127.0.0.1:4177/?v=navfix5#/demo
```
