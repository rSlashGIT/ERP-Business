M5 raw dataset (calendar.csv, sales_train_evaluation.csv, sales_train_validation.csv,
sell_prices.csv, sample_submission.csv) was excluded from this archive (430 MB).

To restore:
  1. Download from Kaggle M5 Forecasting Competition:
     https://www.kaggle.com/competitions/m5-forecasting-accuracy/data
  2. Place the 5 CSV files in this data/m5/ directory.

All processed/derived data needed to run the frontend and reproduce results
is included in data/processed/.
